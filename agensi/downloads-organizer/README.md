# Downloads Organizer

Turns a messy Downloads folder into tidy type and topic folders (`Documents/Resumes/`, `Images/Screenshots/`) without the risk. Your agent shows a dry-run plan first, lets you rename or regroup anything, and moves nothing until you type `yes`. It never deletes, never overwrites, leaves keys and recovery codes untouched, and records every move in an undo log, so one sentence ("undo the last cleanup") puts everything back.

Install by placing this folder in your agent's skills directory (for Claude Code: `~/.claude/skills/downloads-organizer/`), then ask: "organize my Downloads".

Based on the open-source [Personal AI Assistant](https://github.com/brandanpratt/personal-ai-assistant) (MIT), a fully local, Ollama-powered version of the same organizer.
